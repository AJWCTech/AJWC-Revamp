Network Administration & Cyber Resilience

This project analyses and designs a secure network solution for the TerraGaff case study, addressing requirements for multi-floor subnets, dynamic addressing, and secure connectivity. The objective is to propose resilient network architectures, evaluate design options, and apply security principles that support operational reliability and threat mitigation. Technical focus includes IP design, network segmentation, and infrastructure planning to meet both performance and security requirements.

Executive Summary

This report and associated exercises document the design and implementation of network solutions for TerraGaff’s multi-floor office environment. The work addresses requirements for subnet segmentation, dynamic addressing, wireless connectivity, and secure infrastructure design. Set exercises demonstrate practical network administration tasks, journal documentation, and critical evaluation of configuration approaches, aligning with academic and professional networking standards.
