# Placeholders

Every asset the site uses that is **not yet real**. This is the shopping
list for the generation pass.

Regenerate the placeholder files after changing dimensions in
`src/content/assets.ts`:

```bash
py scripts/build-placeholders.py
```

Swapping one in is a one-line edit in `src/content/assets.ts` — change
`path` and set `placeholder: false`. Because `width` and `height` are
declared in the manifest and passed to `next/image`, the layout does not
shift when a real asset lands.

## Not placeholders

These are genuine and need no work:

- `work-kritikal`, `work-umbra`, `work-white-phoenix` — real screenshots
  of shipped client sites, carried over from the previous build.

- The Open Graph card — generated at request time by
  `src/app/opengraph-image.tsx`, so it cannot drift from the site copy.
